# Dépôt de fichiers

Déposer ici un CSV avec une colonne `date` et une colonne par série, puis lancer :

```bash
python -m tools.ingestion
```

Chaque colonne numérique devient une série dans `data/catalogue.csv`. Compléter ensuite l'unité, la source et l'adresse. Détails dans `docs/ajouter-des-donnees.md`.
